# Striver's A2Z DSA Sheet - C++ Solutions

This repository contains my personal solutions and implementations for problems from the **[Striver's A2Z DSA Sheet / Course](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2)** implemented in modern **C++**.

---

## 📁 Repository Structure & Topic Overview

| Category | File(s) | Topics Covered |
| :--- | :--- | :--- |
| **Basics & Math** | `basicMath.cpp`, `basicHashing.cpp`, `loops.cpp`, `patterns.cpp`, `STL.cpp` | Number theory, frequency hashing, star patterns, C++ STL containers & algorithms |
| **Bit Manipulation** | `learnbitmanipulation.cpp`, `Bitsinterviewprobs.cpp`, `BitsAdvancedMaths.cpp` | Bit operations, power set, XOR properties, bit math |
| **Arrays & Sorting** | `Sorting.cpp`, `arrayeasyques.cpp`, `arraymedques.cpp`, `arrayhardques.cpp` | Sorting algos, Kadane's, Dutch National Flag, Pascal's Triangle, 3-Sum, Subarrays |
| **Binary Search** | `BinarySearchwithSTL.cpp`, `bson1Darrays.cpp`, `bson2Darrays.cpp`, `bsonanswers.cpp` | Lower/Upper bound, rotated arrays, BS on answers (Aggressive Cows, Book Allocation, etc.), 2D matrices |
| **Strings** | `stringeasyques.cpp`, `stringmedques.cpp` | Anagrams, string matching, palindromes, roman numerals |
| **Linked List** | `1DLL.cpp`, `1DLLmedques.cpp`, `2DLL.cpp`, `2DLLmedques.cpp`, `LLhardques.cpp` | Singly & Doubly LL operations, cycle detection, reversing in K-groups, flattening |
| **Recursion & Backtracking** | `recSubsPatt.cpp`, `tryingoutall.cpp` | Subsequences, combinations, subsets |
| **Stacks & Queues** | `LearningStAndQ.cpp`, `implementation.cpp`, `pre,in,postfix.cpp`, `montoStAndQ.cpp` | Stack/Queue using arrays & lists, infix/postfix/prefix conversions, monotonic stack problems |
| **Sliding Window & Two Pointers**| `SWand2PCombmedques.cpp`, `SWand2PCombhardques.cpp` | Fixed & dynamic sliding windows, two pointers techniques |
| **Heaps / Priority Queues** | `HeapsLearning.cpp`, `HeapsMedques.cpp`, `HeapsHardques.cpp` | Min/Max Heap operations, K-th largest/smallest, median in data stream |
| **Binary Trees & BST** | `BTreeTraversals.cpp`, `BTreemedques.cpp`, `BTreehardques.cpp`, `BSTProblems.cpp` | Inorder/Preorder/Postorder/Level order, diameter, LCA, views, BST operations & validations |
| **Graphs** | `graphsLearning.cpp`, `graphsBDFS.cpp`, `graphsTopoSort.cpp`, `graphsSPA.cpp`, `graphsMSTAndDs.cpp`, `graphsOtherAlgos.cpp` | BFS, DFS, Topological sort, Dijkstra, Bellman-Ford, Floyd-Warshall, Prim's, Kruskal's (DSU), Kosaraju, Bridges |
| **Dynamic Programming** | `IntroToDP.cpp`, `1DDP.cpp`, `2DDP.cpp`, `DPOnSubsequences.cpp`, `DPOnStrings.cpp`, `DPOnStocks.cpp`, `DPonLIS.cpp`, `partitionDP.cpp` | Memoization, tabulation, space optimization across 1D, 2D, grids, strings, stocks, LIS, and matrix chain / partition DP |
| **Greedy Algorithms** | `greedyAlgoeasyques.cpp`, `greedyAlgomed-hardques.cpp` | Activity selection, jump game, fractional knapsack, job sequencing |

## 🛠️ How to Compile & Run

Using `g++` (C++17 or above recommended):

```bash
g++ -std=c++17 <filename>.cpp -o output
./output
```
